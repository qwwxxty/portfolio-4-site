# туманчик — сайт-візитка вейпшопу в Сумах

Демонстраційний односторінковий сайт для портфоліо. Бренд, асортимент, ціни та контакти вигадані.

Чистий HTML, CSS і JavaScript: без збирання та залежностей, тож сайт одразу працює на GitHub Pages.

## Структура

```
index.html          розмітка всіх розділів
css/style.css       стилі (спочатку мобільна версія; брейкпоінти 640 / 900 / 1100 / 1280 px)
js/main.js          інтерактив
assets/favicon.svg  іконка вкладки
.nojekyll           вимикає обробку Jekyll на GitHub Pages
```

## Розділи

1. Перевірка віку 18+ (запам’ятовується в `localStorage`)
2. Шапка з навігацією, живим статусом «відчинено / зачинено» за київським часом і кнопкою «Подзвонити»
3. Перший екран: заголовок, кнопки «Подзвонити», Telegram, Instagram, туман на canvas
4. Про нас і лічильники
5. Каталог із фільтром за категоріями
6. Переваги
7. Сервіс із прайсом
8. Як замовити (три кроки)
9. Клубна картка
10. Галерея простору
11. Відгуки (слайдер)
12. Часті запитання
13. Контакти, схема проїзду, форма зворотного дзвінка
14. Підвал з юридичним попередженням
15. Нижня панель «Подзвонити / Telegram / Instagram» на мобільних

## Як замінити заглушки фото

Кожна заглушка в `index.html` має такий вигляд:

```html
<figure class="media ...">
  <div class="ph"><span>Фото · інтер’єр</span></div>
</figure>
```

Замініть `<div class="ph">…</div>` на зображення, а клас і обгортку `figure` залиште:

```html
<figure class="media ...">
  <img src="images/interior.jpg" alt="Інтер’єр крамниці" loading="lazy">
</figure>
```

Зображення саме заповнить рамку (`object-fit: cover`), паралакс і анімація появи продовжать працювати.
Знайти всі місця можна пошуком за `class="ph"` або коментарем `ЗАГЛУШКА`.

Рекомендовані пропорції:

| Місце | Пропорція |
| --- | --- |
| Перший екран, «Про нас» (арки) | 4:5, вертикальні |
| Деталь у «Про нас», картки товарів | 1:1 |
| Сервісна стійка | 3:2 |
| Галерея | вертикальні або квадратні, від 1200 px |

## Що замінити на реальні дані

Знайдіть і замініть у `index.html`:

- `+380990000000` і `+380 99 000 00 00` — телефон;
- `https://t.me/tumanchyk_sumy` — Telegram;
- `https://instagram.com/tumanchyk.sumy` — Instagram;
- `вул. Соборна, 21` — адреса (і посилання «Маршрут» на Google Maps);
- години роботи: у тексті сторінки та константи `OPEN` / `CLOSE` у функції `initStatus` у `js/main.js`.

Форма зворотного дзвінка зараз демонстраційна: вона перевіряє поля й показує повідомлення, але нікуди не надсилає дані.
Щоб заявки надходили, підключіть Formspree або webhook Telegram-бота: місце позначене коментарем `ДЕМО` у `js/main.js`.

## Локальний запуск

```bash
python3 -m http.server 8000
```

Потім відкрийте http://localhost:8000.

## Публікація на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, гілка `main`, папка `/ (root)`.

## Доступність і продуктивність

- семантична розмітка, посилання «Перейти до змісту», видимий фокус, підписи для кнопок з іконками;
- `prefers-reduced-motion`: анімації, паралакс і туман вимикаються;
- туман рендериться в половинній роздільності й зупиняється, коли перший екран поза видимістю або вкладка неактивна;
- якщо `main.js` не завантажився, сторінка показується повністю, без анімацій.
